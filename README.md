# FinSight

Build a premium enterprise-grade AI-powered financial risk intelligence platform called "GlobalRisk AI" with a modern Bloomberg/Stripe-inspired dark UI, glassmorphism, responsive layout, and smooth animations. Include an Executive Dashboard, Corporate Intelligence Repository (drag-and-drop PDF upload, OCR, multi-company & multi-year reports, metadata, versioning, search, processing status), Corporate Risk Intelligence Engine (AI risk extraction, categorization, NER, topic extraction, severity, confidence scores, explainable summaries), Evidence Viewer (side-by-side disclosure comparison, semantic highlights, AI explanations, citations, source navigation), Risk Evolution Analytics (new/removed risks, severity changes, emerging themes, timelines, heatmaps), Financial Health Intelligence (KPIs, charts, AI insights, risk correlation), Market Intelligence (news feed, SEBI/SEC filings, sentiment analysis, alerts), Industry Intelligence (peer comparison, rankings, sector heatmaps), Risk Explorer (semantic filters for Governance, Cyber, ESG, Climate, Regulatory, Litigation, Supply Chain, AI Regulation, Auditor Concerns, Financial Stability), Multi-Factor Risk Scanner (AND/OR custom screening), Executive Report Generator (downloadable PDF reports), Analyst Workspace (watchlists, saved reports, notes, favorites), PDF Annotation Workspace (highlights, comments, AI suggestions), Authentication with team workspaces, dark/light mode, interactive charts, timelines, heatmaps, AI assistant, Framer Motion animations, skeleton loaders, keyboard shortcuts, and fully responsive professional SaaS design with every AI insight linked to source evidence and confidence indicators.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
